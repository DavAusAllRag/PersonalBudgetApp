# PersonalBudgetApp
A rough around the edges app designed to keep up to date personal financial tracking and subsequent budgeting metrics ultizing the Plaid API Service. 

The goal of this project is to both track spending habits using manual upkeeping for neccessary purchases by calling to CapitalOne Banking's API to track CC purchases. 
Some statitics that will be tracked is % of transaction method (CC, Cash, Re-occuring) 
Then intend on setting goals and milestones for personal money saving motivation.
